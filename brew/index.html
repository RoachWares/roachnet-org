RoachNet Brew

Terminal type? Three commands to ~/RoachNet.

Same app, same folder, same easy goodbye if you change your mind. This route skips the setup window and lets Homebrew do the walking.

Apple Silicon only. Needs Homebrew. If you don't have it yet, install it first, then come back. RoachNet will wait.

Installs RoachNet 1.0.6 · DMG SHA-256 28ed912658901a36d43312b21aa67f5fd1768cd8fd30e015431fef14ec2f9d0d · brew update && brew tap --force RoachWares/roachnet && brew install --cask roachnet

RoachNet v1.0.6 is not Apple-notarized yet, so the cask clears only the macOS flags that would block launch, then runs the same native installer the Setup app uses. It brings its own tools instead of borrowing yours.

brew update brew install --cask roachnet ~/RoachNet/app All in one folder

Install

Three steps. Same destination.

1

Add the tap.

brew update && brew tap --force RoachWares/roachnet

2

Install the cask.

brew install --cask roachnet

3

Launch.

open ~/RoachNet/app/RoachNet.app

Use Setup.app instead

What it installs

What lands on disk.

App bundle

~/RoachNet/app/RoachNet.app

The same app the Setup app installs, cleared so macOS opens it without an argument. The Setup app itself stays in ~/RoachNet/setup for repairs.

Storage root

~/RoachNet/storage

Models, logs, the vault and everything else live here. Nothing gets scattered into /usr/local, /tmp, or some staging folder you'll never find again.

Local tools

~/RoachNet/bin

Helper tools sit next to the app. Clean install, clean uninstall, nothing left behind for future-you to curse at.

Config writes

~/Library/Application Support/roachnet

A small settings file so the app knows where everything is the first time it opens. No scavenger hunt.

Homebrew runtime

More than a brew install in a trenchcoat.

Native installer

The cask runs RoachNet's own Swift installer: preflight checks, a smoke test, and a swap that keeps your storage. No Node, no source tree, nothing global.

Launch-safe

Clears the macOS quarantine flags that stop a fresh download from opening, and only those. Nothing else gets touched.

Cache that stays put

Cache lives in ~/RoachNet/storage/state/runtime-cache, not /tmp. It won't vanish on reboot and act surprised next launch.

Safer first boot

The phone bridge stays off until you turn it on. If the first launch goes sideways, RoachNet tries to fix itself once before it bothers you.

Logs in one place

All logs live in ~/RoachNet/storage/logs. When something breaks, you know exactly where to look.

Identical either way

Same API and same behaviour as the Setup app install. Only the route is different.
